💡 PDF 퀵 에디터 사용법

📁 기본 조작

  • PDF 열기: 파일을 화면에 드래그하거나 중앙 영역을 클릭하세요.
  • 추가 (병합): 왼쪽 사이드바 상단의 [추가] 버튼으로 다른 PDF나 이미지를 현재 문서 끝에 붙일 수 있습니다.

🖱️ 페이지 편집

  • 순서 변경: 왼쪽 썸네일을 드래그하여 페이지 순서를 바꿀 수 있습니다.
  • 회전: 페이지를 선택하고 [90° 회전] 버튼을 누르면 회전됩니다.
  • 삭제: 썸네일 위의 [×] 버튼이나 상단 [현 페이지 삭제]를 사용하세요.
  • 다중 선택: Ctrl (또는 Cmd) 키를 누른 채 클릭하면 여러 페이지를 선택해 일괄 회전/삭제가 가능합니다.

✏️ 도구 모음

  • 선택: 편집한 요소를 다시 선택하여 이동하거나 크기를 조절합니다.
  • 마커: 중요 부분을 형광펜(노랑/빨강)으로 강조하거나 검정색으로 가립니다.
  • 텍스트: 원하는 위치에 글자를 추가합니다. (폰트/크기/색상 변경 가능)
  • 번호 넣기: 페이지에 번호를 자동으로 매기거나 직접 입력합니다.
  • 서명: 마우스나 터치로 서명하여 문서에 삽입합니다.

💾 저장 및 내보내기

  • 그림으로 저장: 현재 보고 있는 페이지를 고화질 이미지로 저장합니다.
  • PDF 내보내기: 편집된 모든 내용을 포함한 최종 PDF 파일을 다운로드합니다.
